# 🕌 Tantangan Kisi-Kisi SKI (Sejarah Kebudayaan Islam)

**Tantangan Kisi-Kisi SKI** adalah game kuis edukatif berbasis web (*single-file HTML/CSS/JavaScript*) yang dirancang untuk melatih pemahaman siswa madrasah terhadap materi **Sejarah Kebudayaan Islam (SKI)** secara interaktif, menarik, dan menantang.

---

## ✨ Fitur Utama Game

* **📚 4 Tipe Soal Berstandar Evaluasi Modern:**
  * **10 Soal Pilihan Ganda Biasa:** Analisis kasus sejarah dan kepemimpinan profetik.
  * **5 Soal Pilihan Ganda Kompleks:** Memilih 2 jawaban tepat berbasis penalaran.
  * **5 Soal Benar / Salah:** Menguji ketelitian fakta sejarah (4 pernyataan per soal).
  * **5 Soal Menjodohkan:** Mencocokkan konsep, tokoh, dan peristiwa sejarah.
* **❤️ Sistem Nyawa (*Survival Mode*):** Pemain dibekali **3 nyawa**. Setiap kesalahan mengurangi 1 nyawa sehingga melatih ketelitian sebelum mengunci jawaban.
* **⏱️ Timer Dinamis:** Batas waktu menyesuaikan tingkat kompleksitas tiap jenis soal (45–65 detik).
* **🔥 Sistem Skor & Kombo:** Menjawab benar secara cepat dan beruntun akan menghasilkan bonus poin berlipat.
* **💡 Pembahasan Otomatis:** Umpan balik instan berupa koreksi warna (hijau/merah) beserta penjelasan materi setiap selesai menjawab.
* **🔀 Pengacakan Otomatis (*Shuffle*):** Urutan soal selalu diacak setiap kali permainan dimulai ulang.
* **📱 Responsif & Ringan:** Dapat dimainkan langsung di HP, tablet, maupun laptop tanpa perlu koneksi database atau instalasi tambahan.

## 📖 Cakupan Materi Kisi-Kisi

1. **Kondisi Sosio-Kultural Arab Pra-Islam:** Fanatisme kabilah (*ashabiyah*), peran sastra syair, tradisi luhur, dan gerakan spiritual kaum *Hunayif*.
2. **Dakwah Periode Makkah:** Strategi *sirriyah* di Darul Arqam, golongan *As-Sabiqunal Awwalun*, dakwah *jahriyah* (QS. Al-Hijr: 94), pemboikotan Syi'b Abi Thalib, hijrah ke Habasyah, *Amul Huzni*, dan peristiwa Tha'if.
3. **Dakwah Periode Madinah:** Bai'at Aqabah I & II, Piagam Madinah (*Shahifah al-Madinah*), persaudaraan Muhajirin dan Anshar, Perang Badar, Perang Uhud, hingga amnesti massal *Fathu Makkah*.
4. **Pendekatan Kurikulum Berbasis Cinta (KBC):** Internalisasi nilai kemanusiaan, kasih sayang (*rahmatan lil 'alamin*), toleransi, dan moderasi beragama.

## 🚀 Cara Menjalankan & Publikasi (GitHub Pages)

### A. Menjalankan Secara Lokal (Offline)
1. Unduh file `index.html` (atau `game-ski.html`) dari repositori ini.
2. Klik dua kali file tersebut untuk membukanya di browser (Chrome, Edge, Safari, atau Firefox).

### B. Mengubah Menjadi Tautan (*Link*) Online via GitHub Pages
1. Pastikan file utama game diberi nama **`index.html`** di dalam repositori ini.
2. Buka menu **Settings** di repositori GitHub Anda.
3. Pilih tab **Pages** di menu sebelah kiri.
4. Pada bagian **Build and deployment > Branch**, pilih **`main`** (folder `/root`), lalu klik **Save**.
5. Tunggu sekitar 1–2 menit hingga tautan game muncul (contoh: `https://github.io`), lalu bagikan tautan tersebut kepada siswa!

## 🛠️ Teknologi yang Digunakan

* **HTML5** — Struktur semantik aplikasi.
* **CSS3** — Tata letak responsif (*Flexbox & CSS Grid*) dengan palet warna bernuansa Islami.
* **Vanilla JavaScript (ES6)** — Manajemen *state* permainan, pengacakan soal, timer, validasi jawaban multi-tipe, dan kalkulasi skor.
